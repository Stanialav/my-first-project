# Чаты

Хранилище результатов работы по чатам с агентами. Папку `chats/` можно открыть в Obsidian как хранилище (vault), или открыть весь репозиторий.

## Структура

```
chats/
├── README.md                     ← этот файл: правила и список чатов
├── _шаблон/
│   └── README.md                 ← шаблон заметки для нового чата
└── ГГГГ-ММ-ДД_короткое-название/ ← одна папка = один чат
    ├── README.md                 ← задача, что сделано, ссылки, итог
    └── ...                       ← файлы, скриншоты, логи, черновики
```

## Правила

1. Один чат — одна папка `ГГГГ-ММ-ДД_короткое-название` (строчные буквы, слова через дефис).
2. В каждой папке есть `README.md`, созданный по шаблону из `_шаблон/README.md`.
3. Всё, что получилось в чате (тексты, файлы, скриншоты, ссылки на PR), кладётся в папку этого чата.
4. После работы изменения коммитятся и пушатся в GitHub. Obsidian получает их через плагин Obsidian Git или через `git pull`.
5. Новый чат добавляется в список ниже.
