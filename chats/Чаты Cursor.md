# Чаты Cursor

Результаты работы по чатам с агентами Cursor. Агенты сохраняют их на GitHub, а на компьютере эта папка лежит внутри хранилища Obsidian «Stas» (`Входящие/Cursor/chats`) и обновляется сама каждые 10 минут.

## Структура

```
chats/
├── Чаты Cursor.md                          ← этот файл: правила и список чатов
├── _шаблон/
│   └── Шаблон чата.md                      ← шаблон заметки для нового чата
└── ГГГГ-ММ-ДД_короткое-название/           ← одна папка = один чат
    ├── ГГГГ-ММ-ДД_короткое-название.md     ← задача, что сделано, ссылки, итог
    └── ...                                 ← файлы, скриншоты, логи, черновики
```

## Правила

1. Один чат — одна папка `ГГГГ-ММ-ДД_короткое-название` (строчные буквы, слова через дефис).
2. Главная заметка чата называется так же, как папка, и создаётся по шаблону `_шаблон/Шаблон чата.md`.
3. Всё, что получилось в чате (тексты, файлы, скриншоты, ссылки на PR), кладётся в папку этого чата.
4. После работы изменения коммитятся и пушатся в GitHub.
5. Новый чат добавляется в список ниже.

Папку на компьютере редактировать не нужно: при обновлении она приходит с GitHub. Свои заметки по итогам чата лучше делать рядом, в других папках хранилища, со ссылкой на заметку чата.
