# Структура папок для чатов

## Задача

Создать папку с подпапками для каждого чата, складывать туда результаты работы и сохранять их в Obsidian. Если структура неудачная, предложить варианты.

## Что сделано

- Создана папка `chats/` с правилами ([[Чаты Cursor]]) и шаблоном ([[Шаблон чата]]).
- Создана эта папка как первая запись.
- В корень репозитория добавлен `AGENTS.md`. Агенты читают его автоматически, так что каждый следующий чат сам сохранит результаты в `chats/`.
- Первый вариант (отдельное хранилище `my-first-project`) заменён: у пользователя уже есть хранилище «Stas» по схеме PARA, куда сохраняет Грок. Теперь чаты Cursor попадают туда же, в папку `Входящие/Cursor`.

## Варианты структуры

1. **По чатам (выбран сейчас):** `chats/ГГГГ-ММ-ДД_название/`. Это просто, и папки идут по дате.
2. **По проектам, внутри по чатам:** `проекты/<проект>/чаты/ГГГГ-ММ-ДД_название/`. Удобно, если чатов по одному проекту много (например, «ИИ-кабинет бухгалтера» из репозитория `ii`).
3. **По типу результата:** `код/`, `документы/`, `исследования/`, с тегом чата в каждой заметке. Удобно искать по типу, но работа из одного чата оказывается в разных местах.
4. **PARA (Проекты / Области / Ресурсы / Архив):** так уже устроено хранилище «Stas». Чаты приходят во «Входящие», а оттуда их можно связывать с проектами.

## Как это работает

- Агенты в облаке сохраняют чат в `chats/` на GitHub.
- На компьютере в хранилище «Stas» лежит папка `Входящие/Cursor`. В ней копия только папки `chats/` из репозитория (остальной код туда не попадает).
- Задача Windows «Cursor chats pull» каждые 10 минут без окон забирает новое с GitHub. Obsidian сразу показывает новые заметки.
- Настройки Obsidian, плагины и то, что сохраняет Грок, не меняются.

## Установка на компьютер (делается один раз)

Windows: нажать Пуск, ввести `PowerShell`, открыть его и вставить:
```
[Net.ServicePointManager]::SecurityProtocol = 'Tls12'; iex ([Text.Encoding]::UTF8.GetString((iwr -UseBasicParsing https://cdn.jsdelivr.net/gh/Stanialav/my-first-project@main/setup/windows.ps1).RawContentStream.ToArray()))
```

macOS: открыть «Терминал» и вставить:
```
curl -fsSL https://cdn.jsdelivr.net/gh/Stanialav/my-first-project@main/setup/mac-linux.sh | bash
```

Адрес `raw.githubusercontent.com` в России часто заблокирован, поэтому скрипт скачивается через jsDelivr. Дальше нужен только доступ к `github.com`.

Как удалить: в PowerShell выполнить `schtasks /Delete /TN "Cursor chats pull" /F` и удалить папку `Входящие/Cursor` из хранилища.

## Итог и что дальше

Чаты Cursor приходят в хранилище «Stas» в `Входящие/Cursor/chats`. Структуру можно поменять позже.
