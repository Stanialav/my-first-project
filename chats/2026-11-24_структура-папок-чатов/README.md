# Структура папок для чатов

## Задача

Создать папку с подпапками для каждого чата, складывать туда результаты работы и сохранять их в Obsidian. Если структура неудачная, предложить варианты.

## Что сделано

- Создана папка `chats/` с правилами (`chats/README.md`) и шаблоном (`chats/_шаблон/README.md`).
- Создана эта папка как первая запись.
- В корень репозитория добавлен `AGENTS.md`. Агенты читают его автоматически, так что каждый следующий чат сам сохранит результаты в `chats/`.

## Варианты структуры

1. **По чатам (выбран сейчас):** `chats/ГГГГ-ММ-ДД_название/`. Это просто, и папки идут по дате.
2. **По проектам, внутри по чатам:** `проекты/<проект>/чаты/ГГГГ-ММ-ДД_название/`. Удобно, если чатов по одному проекту много (например, «ИИ-кабинет бухгалтера» из репозитория `ii`).
3. **По типу результата:** `код/`, `документы/`, `исследования/`, с тегом чата в каждой заметке. Удобно искать по типу, но работа из одного чата оказывается в разных местах.
4. **PARA (Проекты / Области / Ресурсы / Архив):** популярная схема для Obsidian. Чаты лежат внутри проектов, а законченное уходит в архив.

## Как подключить к Obsidian

- **Вариант A (рекомендуется):** клонировать репозиторий `my-first-project` на компьютер, открыть его в Obsidian как хранилище и поставить плагин **Obsidian Git** с автоматическим pull. Тогда всё, что сохраняют агенты, само появляется в Obsidian.
- **Вариант B:** отдельный репозиторий только под Obsidian, например `obsidian-vault`, куда агенты пишут заметки.
- **Вариант C:** скачивать папку вручную и копировать её в хранилище.

## Итог и что дальше

Нужно выбрать вариант структуры и способ синхронизации с Obsidian. По умолчанию работает вариант 1 + A.
